# 논문 작성 활용 가이드

## 1. 어떤 순서로 쓰나
1. 파이프라인이 끝나면(Approve 이상) 상세 패널 **논문 도구 → 보고서 새로 생성**을 누릅니다(AI 요약 포함).
2. 보고서 맨 위 **논문 사용 전 점검 사항**을 먼저 읽고, 해당되는 항목을 해결하거나 논문의 한계 절에 기술합니다.
3. **논문 패키지 ZIP**을 받아 `report.md`의 표·문장을 논문 원고로 옮기고, `figures/`의 그림을 삽입합니다.

## 2. 보고서 절 ↔ 학위논문 장 대응(권장)
| 보고서 | 논문에서의 위치 |
|---|---|
| 1. 연구 질문과 설계 (표 1·2) | 연구 설계·방법론 |
| 2. 실증 보정 데이터 (표 3, 부록 A1, 그림 5) | 자료 및 보정 |
| 3. 시뮬레이션 결과 (표 4~8, 그림 1~3) | 분석 결과 |
| 4. 강건성 검증 (표 9) | 강건성 검토 |
| 5. 인간 검토자 보정 (표 10·11, 그림 4) | 인간 행동 실험 결과 |
| 6~9. 판정·논의·한계 | 논의 및 결론 |
| 부록 B 재현성 정보 | 부록: 재현 절차 |

## 3. 그림
- **PNG**: 폭 6인치 기준 ×3 ≈ 360dpi. 학위논문 본문에 그대로 사용 가능.
- **SVG**: 벡터라 확대해도 선명하며 글꼴·색을 편집할 수 있습니다.
- 모든 그림은 흰 배경, 색각 이상에서도 구분되는 팔레트이며 수치 라벨을 함께 표시해 흑백 인쇄에서도 읽힙니다.
- 캡션은 보고서 본문에 있습니다(`그림 N.` 형식).

## 4. 해석 시 주의
- **표 5의 변수별 비율은 주변(marginal) 비율**입니다. 다른 변수를 통제한 인과효과가 아닙니다.
- **신뢰구간은 Wilson 95%**이며 후보 수·관측 수가 적으면 넓습니다.
- 계산 엔진의 손실·지급정지 함수는 아직 일반화된 구조 모델입니다. 학위논문의 실제 손실함수·81개 사례 보정을 반영하기 전에는 예비 결과로 표기하세요.
- 문장형 요약·논의는 AI 초안입니다. 인용 전 표의 수치와 직접 대조하세요.
- 자동 승인(`AUTO_APPROVE=true`)으로 확정된 판정은 논문에 "자동 판정"임을 밝히고, 사람의 검토 절차를 별도로 기술하세요.

## 5. 재현성
`data/thesis_data.json`에 설계 시드, 제약, 후보별 결과, 검토자 집계, 사례 패널이 모두 들어 있고 `tables/audit_log.csv`에 실행 이력이 남습니다. 같은 프로젝트 설정으로 재실행하면 같은 후보가 추출됩니다(결정적 시드).
